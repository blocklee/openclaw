# 可信执行环境+加密执行 PPT

## 项目概述
这是一个关于"可信执行环境+加密执行（Skill资产化后加密执行）"的专业演示文稿，旨在向投资者、技术合作伙伴和潜在客户解释这一创新概念。

## 文件结构

### 主要文件
1. **TEE_Presentation.html** - 完整的HTML版本PPT（推荐使用）
2. **presentation.md** - Marp格式的Markdown源文件
3. **ppt_content.md** - 详细的PPT内容（Markdown格式）
4. **project_plan.md** - 项目计划和结构说明

### 辅助文件
- **README.md** - 本说明文件

## 如何查看PPT

### 推荐方式：HTML版本
1. 直接在浏览器中打开 `TEE_Presentation.html`
2. 支持功能：
   - 键盘导航（上下箭头、PageUp/PageDown、空格键）
   - 响应式设计（适配手机和桌面）
   - 现代视觉效果

### 备用方式：Marp版本
如果需要转换为PPTX/PDF格式：
```bash
# 安装Marp CLI
npm install -g @marp-team/marp-cli

# 转换为PPTX
marp presentation.md --pptx --output TEE_Presentation.pptx

# 转换为PDF
marp presentation.md --pdf --output TEE_Presentation.pdf
```
