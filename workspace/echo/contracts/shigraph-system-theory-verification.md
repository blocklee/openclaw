## 一、K-core + Katz 框架的严格定义验证

### 1.1 标准 K-core 分解

**定义**（Bollobás 1984）：图 G=(V,E) 的 k-core 是 V 的最大子集 S，使得 ∀v∈S, deg_S(v) ≥ k。

**shigraph 映射**：
- 节点 = 创作者作品
- 边 = 衍生/编排/收益关系
- K-core 深度 = 作品在网络中的"核心嵌入层级"

**关键差异**：
| 属性 | 标准 K-core | shigraph 变体 |
|------|-----------|--------------|
| 二值性 | 是（在核内/不在） | **否**（连续势位值） |
| 时间维度 | 无 | 有（时间衰减） |
| 边权重 | 无 | 有（四权属性+亲代稀释） |

**结论**：shigraph 不是标准 K-core，是**带时间衰减的加权 K-core 连续变体**。

### 1.2 Katz 中心性

**定义**（Katz 1953）：
```
C_Katz(v) = Σ_{k=1}^∞ Σ_{u} α^k (A^k)_{uv}
```
其中 A 是邻接矩阵，α < 1/λ_max 是衰减因子。

**shigraph 映射**：
- A_{uv} = 1 如果存在 u→v 的衍生/编排边
- α = 时间衰减因子（24h/30天窗口）
- 路径长度 k = 衍生链深度

**关键差异**：
| 属性 | 标准 Katz | shigraph 变体 |
|------|----------|--------------|
| 衰减因子 | 全局常数 α | **分段函数**（24h内α=1, 30天内α=0.5, 外α=0） |
| 边权重 | 二元 | **连续**（亲代稀释权重：100%/80%/50%/10%） |
| 节点属性 | 无 | **四权属性叠加**（用权/衍权/扩权/益权作为额外权重） |

**结论**：shigraph 不是标准 Katz，是**带分段衰减+边权重+节点属性的 Katz 变体**。

### 1.3 综合框架：shigraph 嵌入深度公式

```
D_sgi(v) = Σ_{k=1}^{K_max} Σ_{u∈N_k(v)} w(u,v) × α(t_u) × β(four_rights_u)

其中：
- N_k(v) = 距离 v 为 k 的节点集合
- w(u,v) = 边权重（亲代稀释后）
- α(t_u) = 时间衰减函数（分段）
- β(four_rights_u) = 四权属性函数（0-1之间）
- K_max = 最大路径深度（合约中 MAX_CYCLE_DEPTH=10）
```

**验证结果**：
✅ K-core 结构直觉可用（核心/边缘分层）  
✅ Katz 路径加权可用（远程引用衰减）  
⚠️ 但两者都是**变体**，不是标准定义——需要重新定义收敛条件

## 二、可调控序参量（Tunable Order Parameter）的数学存在性

### 2.1 序参量的 Landau 定义

**标准定义**：在相变点附近，自由能 F 可展开为：
```
F(ψ) = F_0 + a(T-T_c)ψ² + bψ⁴ + ...
```
其中 ψ 是序参量，T_c 是临界温度。

**关键属性**：
1. ψ 在无序相为 0，有序相非 0
2. ψ 是宏观涌现量（从微观相互作用产生）
3. ψ 可被控制参数（如温度）间接调控

### 2.2 势位作为序参量

**映射验证**：

| Landau 属性 | shigraph 势位 | 验证结果 |
|------------|-------------|---------|
| 无序相 ψ=0 | 势位=0（新作品/零入度） | ✅ |
| 有序相 ψ≠0 | 势位>0（被引用/衍生） | ✅ |
| 宏观涌现 | 从入度/出度/时间衰减涌现 | ✅ |
| 控制参数间接调控 | 传统：只能通过增加入度间接改变 | ⚠️ |

### 2.3 "可调控"的偏离

**标准序参量**：只能通过控制参数间接改变（如调温度→磁化变）。

**势位的特殊性**：DAO 可直接 `setPotential=0`——相当于用手直接拨乱磁铁的自旋。

**数学表述**：
```
标准：dψ/dt = f(控制参数)
shigraph：dψ/dt = f(控制参数) + g(外部直接干预)
```

**结论**：势位不是标准序参量，是**受驱序参量（driven order parameter）**，带有外部控制项 g。

### 2.4 受驱序参量的稳定性条件

引入外部干预后，系统稳定性需要额外条件：

```
稳定性条件：|g(外部干预)| < |∂f/∂ψ|_ψ=ψ_eq

即：外部干预的强度必须小于系统自我恢复力的梯度
```

**工程含义**：
- DAO setPotential=0 的权限必须受时间锁约束（不能频繁干预）
- 否则外部干预会压倒系统的自我恢复，导致持续振荡
- **建议**：DAO 权限添加最小干预间隔（如 7 天冷静期）

## 三、滞后效应（Hysteresis）的数学存在性

### 3.1 磁滞回线的定义

**物理定义**：系统的响应取决于历史路径，而非仅当前状态。
```
ψ_上升(T) ≠ ψ_下降(T)  for T ∈ [T_c - Δ, T_c + Δ]
```

### 3.2 势位滞后的来源

shigraph 中的滞后效应来自**时间衰减窗口**：

```
势位归零路径：
  t=0: 势位 = P_high（高值）
  t=t1: DAO setPotential=0 → 势位立即归零
  t=t2: 入度重新积累 → 势位开始恢复
  
  但：时间衰减窗口让 t=0 时的历史引用权重已经蒸发
  → 即使恢复相同拓扑，P(t2) < P(0)（因为历史权重丢失）
```

**数学模型**：
```
P(t) = Σ_{i} w_i × exp(-λ(t - t_i)) × I(t_i > t - T_window)

其中：
- w_i = 第 i 次引用的初始权重
- λ = 衰减系数
- T_window = 时间窗口（30天）
- I = 指示函数（超过窗口的引用权重归零）
```

**滞后面积**：
```
A_hysteresis = ∫_{上升路径} P dT - ∫_{下降路径} P dT
             = Σ_{蒸发权重} w_i × (1 - exp(-λT_window))
```

**数值估计**（假设参数）：
- λ = 0.1/天（10天衰减到 37%）
- T_window = 30天
- 蒸发权重占总权重的 ~5%

→ 滞后面积约等于 5% 的总势位值，意味着恢复后的峰值比原峰值低 5%。

### 3.3 滞后的工程影响

| 场景 | 影响 |
|------|------|
| 误判刷量而归零 | 恢复后势位永久损失 ~5% |
| 创作者主动重置（换新方向） | 历史积累无法完全继承 |
| 申诉成功恢复 | 无法完全回到原状态 |

**建议**：
- 历史权重蒸发不可逆——设计时预留「历史继承」选项（如申诉成功可部分恢复历史权重）
- 但历史继承本身可能成为攻击面（攻击者故意触发归零再申诉，重置稀释计数）

## 四、四权耦合的 Viability Condition

### 4.1 自组织系统的 Viability

**Beer 的 Viable System Model (VSM)**：系统维持自身生存需要 5 个递归管理功能：
1. S1：操作（核心活动）
2. S2：协调（避免振荡）
3. S3：控制（资源分配）
4. S4：情报（环境监测）
5. S5：政策（身份认同）

### 4.2 四权 → VSM 映射

| 四权 | VSM 功能 | 物理意义 |
|------|---------|---------|
| 用权 | S5（政策/身份） | 定义"谁是我们" |
| 衍权 | S1（操作） | 核心活动（创作/改编） |
| 扩权 | S3（控制） | 资源分配（编排权） |
| 益权 | S4（情报/环境） | 能量输入（经济可持续性） |

### 4.3 耦合约束的形式化

**死锁条件**（viability violation）：

```
死锁 = (益权=2 ∧ 扩权=0) ∨ (用权=0 ∧ 衍权≥1) ∨ (衍权=0 ∧ 扩权≥2)

解释：
1. 益权=2（分成）但扩权=0（锁定）→ 能量输入但无法输出 → 热寂
2. 用权=0（私密）但衍权≥1（可改编）→ 边界破裂 → 身份危机
3. 衍权=0（封闭）但扩权≥2（自由编排）→ 无内容可编排 → 空转
```

**验证**：
✅ FourRightsValidator.sol 已编码硬拦截条件 1 和 3  
⚠️ 条件 2（用权=0+衍权≥1）未在合约中显式检查——需要确认是否纳入  

### 4.4 隐性死锁：版本兼容性

**场景**：
- v1.0 作品：用权=2（开放），益权=2（分成），扩权=2（自由编排）
- v2.0 升级：创作者希望扩权降到 1（条件编排），但已授权用户的编排权如何处理？

**死锁**：旧版用户的编排权 ≠ 新版创作者的扩权 → 权利冲突

**当前合约层**：无处理  
**建议**：版本升级时必须明确「旧版权利过渡机制」（如 grandfathering 期）

## 五、攻击面热力图（系统论视角）

### 5.1 相变触发路径

| 攻击路径 | 触发条件 | 相变方向 | 风险等级 |
|---------|---------|---------|---------|
| 刷量攻击 | 入度短时间暴涨 | 泰卦→需卦（繁荣→耗散） | 🔴 高 |
| 清洗攻击 | 高频次微小变更 | 乾卦→坤卦（顶峰→基态） | 🔴 高 |
| 伪孤岛 | 边缘节点虚构引用 | 否卦→泰卦（板结→繁荣假象） | 🟡 中 |
| 合谋套利 | 多钱包互刷 | 泰卦→否卦（繁荣→板结） | 🟡 中 |
| DAO 滥用 | 频繁 setPotential=0 | 任意吸引子→混沌 | 🟠 极高 |

### 5.2 最脆弱节点

**相变临界点最脆弱**：
1. **高势位节点势位归零**（乾卦→坤卦）
   - 触发条件：入度归零或 DAO 干预
   - 系统影响：局部相分离，但周边节点重组
   - 风险：滞后效应导致不可逆损失

2. **新作品冷启动**（坤卦→屯卦）
   - 触发条件：首个引用进入
   - 系统影响：从零势位到非零势位的相变
   - 风险：马太效应导致低势位作品永无出头日

3. **社区结构突变**（泰卦→否卦）
   - 触发条件：核心节点批量出走
   - 系统影响：从开放繁荣到封闭板结
   - 风险：生态死亡螺旋

## 六、结论与建议

### 6.1 验证结果总表

| 系统论属性 | 是否满足 | 偏离程度 | 风险 |
|-----------|---------|---------|------|
| K-core 结构 | ✅ 是 | 加权连续变体 | 低 |
| Katz 中心性 | ✅ 是 | 分段衰减变体 | 低 |
| 序参量涌现 | ✅ 是 | 受驱序参量（有外部干预项） | **中** |
| 滞后效应 | ✅ 存在 | ~5% 不可逆损失 | **中** |
| Viability condition | ⚠️ 部分 | 版本兼容性死锁未处理 | **高** |
| 相变预警 | ✅ 已有6/8防御层 | DAO时间锁+历史继承缺失 | **中** |

### 6.2 建议纳入 V1 的修复

1. **DAO 权限时间锁**：最小干预间隔 7 天（防止受驱序参量振荡）
2. **用权=0+衍权≥1 硬拦截**：FourRightsValidator.sol 补充条件 2
3. **版本升级 grandfathering**：旧版用户权利过渡机制（至少 30 天缓冲期）

### 6.3 建议留 V2 的增强

1. 历史继承机制（滞后效应补偿）
2. 社区结构实时监测（泰卦↔否卦预警）
3. 创作者指纹识别（防止多钱包拆分）
