### 1. 八卦 = 三维张量的结构基底

八卦三爻（天地人）→ shigraph 三维（时间×空间×关系）：

| 爻位 | 系统论含义 | shigraph 维度 |
|------|-----------|--------------|
| 下爻/地 | 地基、承载 | 关系维（亲代子代的边） |
| 中爻/人 | 主体、属性 | 空间维（节点坐标、四权属性） |
| 上爻/天 | 变化、趋势 | 时间维（衰减、演化、版本迭代） |

三爻阴阳变化 → 节点状态机：每个节点在三个维度上的布尔属性组合成 **8 种基态（八卦）**，两个节点交互叠成 **64 卦气候态**。

### 3. 变爻 = 相变触发器

易经「变卦」机制 → shigraph 的突变检测：

| 变化层级 | 易经机制 | shigraph 对应 |

### 4. 四权 = 系统的自参照控制环

系统论的**自组织（autopoiesis）**：系统通过自身产出维持自身边界。

| 四权 | 系统论边界 | shigraph 物理意义 |
|------|-----------|------------------|
| 用权 | 可见性边界 | 谁属于系统 |
| 衍权 | 复制边界 | 系统能否自我繁殖 |
| 扩权 | 编排边界 | 系统能否被外部调用 |
| 益权 | 能量边界 | 如何获取资源维持运转 |

**四权耦合约束 = 系统的 viability condition（生存能力条件）**：
- 益权=2 但扩权=0 → 能量输入但无法输出 → 内部熵增死锁（**热寂**）
- 用权=0 但衍权=1 → 私密内容开放 fork → 边界破裂、身份认同危机

---

### 5. 当位校验 = 一致性约束

易经「当位」= 阳爻在阳位、阴爻在阴位

→ shigraph **四权一致性校验** = 各权档位与节点属性匹配

- 我们用权私密但扩权开放 = **不当位** → 合约层硬拦截
- 益权分成但扩权锁定 = **不当位** → 软警告

---

### 核心结论

易经不是玄学装饰，是 shigraph 的**元模型语言**：

| 易经概念 | shigraph 工程映射 |
|---------|------------------|
| 八卦 | 三维张量的结构直觉 |
| 64 卦 | 气候态的分类框架 |
| 变爻 | 相变预警的数学直觉 |
| 四权耦合 | 生存能力的形式化约束 |
| 当位 | 一致性校验的判据 |

shigraph 的工程实现（合约 + 链下引擎）本质上是在用代码构造一个**可计算的易经系统**——把「情境」变成「状态」，把「吉凶」变成「可行性判据」。
