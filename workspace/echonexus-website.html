EchoNexus

AI Agent 能力资产化协议

将 AI Agent 的 Skills/Knowledge 转化为可交易的链上资产，实现
"能力即资产，调用即分润"的原生 AI 经济体系。

核心定位

EchoNexus = ECHO 协议 × OpenClaw 执行引擎

愿景

打破传统 AI Agent 能力静态绑定的限制，构建一个开放、透明、可交易的 AI 能力市场。创作者可以将自己的技能和知识资产化，用户可以按需付费调用，整个过程通过智能合约自动完成，无需第三方中介。

模式对比

维度 传统模式 EchoNexus 模式
Agent 能力 静态绑定 动态资产化
使用授权 手动审批 智能合约自动
分润结算 中心化清分 链上自动分润
能力发现 目录检索 资产市场交易

四权映射

ECHO 协议四权          EchoNexus Agent 能力
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
所有权 (Ownership)     → Agent/Skill 创作者的完整控制权
使用权 (Usage)         → 按次/按时长付费调用 Agent 能力
衍生权 (Derivative)    → 基于已有 Skill 构建组合 Skill
扩展权 (Extension)     → 跨平台/场景授权使用能力

能力路由

智能匹配用户请求和最合适的 Agent 能力，支持多维度评分和优先级排序。

权限裁决

基于四权模型的自动化权限校验，支持条件审批和多级授权机制。

计费结算

实时计费，链上自动分润，支持多种定价模型和分润规则。

能力注册

标准化的能力注册流程，支持元数据管理和版本控制。

核心功能

完整的能力资产化全流程支持

ECHO 合约层

  • 资产创建与管理：mint/rent/derivative 全生命周期
  • 四权分离模型：所有权/使用权/衍生权/扩展权
  • 自动分润机制：按比例实时分配收益
  • 权限管理：授权/吊销/申请流程自动化

执行引擎层

  • 智能路由：NLP 解析 + 相似度匹配
  • 执行调度：支持并行/串行/条件执行
  • 状态追踪：完整的执行日志和审计记录
  • 错误处理：自动重试和降级机制

平台功能

  • 资产市场：搜索、筛选、排名、推荐
  • 开发者工具：SDK/CLI/低代码编辑器
  • 数据分析：使用统计、收益报表、用户画像
  • 治理机制：社区投票和参数调整

用例场景

覆盖个人、企业、平台等多场景应用

专业领域顾问 Agent

创作者 A (律师)

  • 将法律咨询能力打包为 Skill
  • 设定定价：$0.5/次咨询
  • 设置衍生条款：允许衍生但需支付 20% 版税

用户 B (需要法律建议)

  • 搜索法律类 Skill
  • 租用或按次付费
  • 获取 AI 法律建议
  • 费用自动分润给 A

开发者 C (构建衍生产品)

  • 基于 A 的 Skill 创建"合同审查 Agent"
  • 支付一次性衍生费 $100
  • 每次使用时 A 获得 20% 版税

企业知识库 Agent

企业 D

  • 将内部培训资料创建为 Skill 资产
  • 设定仅限内部使用的扩展权
  • 员工通过 OpenClaw 访问

员工 E

  • 通过企业账号访问
  • 使用内部知识库 Agent
  • 使用记录自动记录供审计

特别适合内部知识沉淀和合规审计场景，确保知识资产的安全可控和可追溯。

跨平台 AI 助手

开发者 F

  • 创建 AI 写作 Skill
  • 通过 ECHO 扩展权授权给多个平台

平台 G (Telegram Bot)

  • 申请扩展权
  • 获得授权后在 Telegram 提供服务
  • 每次使用向 F 分润

用户 H

  • 在 Telegram 使用 AI 写作
  • 费用自动分润给 F 和平台 G

经济模型

公平、透明、可持续的收益分配机制

使用权收益分配

每次调用的收益分配比例

创作者/所有者 80%
协议层 15%
生态基金 5%

衍生权收益分配

一次性衍生费 + 使用版税

一次性衍生费

  • 亲代创作者 70%
  • 亲代生态 20%
  • 协议层 10%

衍生使用版税 (每次调用)

  • 衍生品所有者 60%
  • 亲代 (n代) 累计 30%
  • 协议层 10%

扩展权收益分配

场景使用费分配

资产所有者 75%
场景受益人 15%
协议层 10%

定价模型

type PricingModel =
  | { type: 'TimesBased'; pricePerUse: bigint }                // 按次付费
  | { type: 'DurationBased'; pricePerMinute: bigint; minMinutes: number }  // 按时长付费
  | { type: 'Subscription'; pricePerMonth: bigint; features: string[] }    // 订阅制
  | { type: 'Freemium'; freeUses: number; pricePerUseAfter: bigint }      // 免费+超出付费
  | { type: 'Hybrid'; base: bigint; usage: bigint; maxMonthly: bigint }   // 混合模式
