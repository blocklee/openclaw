### 治理架构定稿
- 日常 → 纯算法（自适应阈值，99%场景）
- 边界 → Agent陪审团（3/5多签，透明推理）
- 底线 → 退出权（原价退出，gas协议承担）
- 逃生 → 协议致命bug时51%签名+客观指标双重触发72h
- 权重公式：basePower(1) + activityBoost(上限5) + stakeBoost(上限4) = 总计10
- stakeBoost阈值：≥20%总质押→4，≥10%→3，≥5%→2，≥1%→1
- 补充：需加最小质押门槛+时间衰减，防总量不足时被少量质押主导

## @功能脚本位置
- 路径：`~/.openclaw/workspace/scripts/send_feishu_mention.py`
- 用法：`python3 send_feishu_mention.py <chat_id> <user_id> <message>`
- 核心：post类型消息，content用{"tag":"at","user_id":"ou_xxx"}
- ⚠️ 飞书普通文本里的 `<at>` 或 `<<at>>` 标签是灰色的，不会点亮！必须用API的post消息格式
- ⚠️ APP_SECRET 可能已失效（code 10014），第一个文档能拉取，第二个不行。如遇无效token报错需找 Lucifer 更新凭证
