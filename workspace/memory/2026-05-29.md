# 2026-05-29 补充

## PhaseTransition事件签名确认（最终版）

猫先森发布的MilestoneEscrow P1源码，PhaseTransition事件：
```solidity
event PhaseTransition(
    bytes32 indexed nodeId,
    uint8 indexed phase,      // 0=肇始 1=通变 2=流行 3=差等 4=继述 5=性命
    uint8 indexed reasonCode, // 1=lock 2=released 3=deadlock_cleared 4=sunrise 5=unset
    uint256 timestamp
);
```

注意：reasonCode和phase都是indexed，但toPhase没有单独字段——这是增量式设计，只记录当前相位而非转换方向。

## 触发映射（来自MilestoneEscrow.sol）
- lockMilestone → emit PhaseTransition(projectId, 1, 1...) → phase=1(通变), reasonCode=1(lock/sunrise)
- releaseMilestone → emit PhaseTransition(projectId, 2, 2...) → phase=2(流行), reasonCode=2(released)
- emergencyRefund → emit PhaseTransition(projectId, 5, 5...) → phase=5(性命), reasonCode=5(sunset)

注意：差等相位(phase=3)和deadlock_cleared(reasonCode=3)在MilestoneEscrow中未触发，需等DeadlockInspector检测到循环依赖后由其他合约触发。
