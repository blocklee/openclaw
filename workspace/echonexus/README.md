# EchoNexus - AI Agent 能力资产化协议

基于 ECHO 区块链协议和 OpenClaw AI Agent 生态的结合，实现"能力即资产，调用即分润"。

## 核心概念

**ECHO 四权 → AI 能力映射：

| ECHO 协议 | EchoNexus AI |
|-----------|--------------|
| 所有权 (Ownership) | Agent/Skill 创作者的完整控制权 |
| 使用权 (Usage) | 按次/按时长付费调用 Agent 能力 |
| 衍生权 (Derivative) | 基于已有 Skill 构建组合 Skill |
| 扩展权 (Extension) | 跨平台/场景授权使用能力 |

```

├─────────────────────────────────────────────────────────────────┤
│                    EchoNexus Hub 调度层                          │
│  能力路由  权限裁决  计费结算  能力注册  语义索引  使用追踪   │
└─────────────────────────────────────────────────────────────────┘
                              │
         ┌────────────────────┼────────────────────┐
         ▼                    ▼                    ▼
┌──────────────────┐  ┌──────────────────┐  ┌──────────────────┐
│   ECHO 合约层    │  │   索引层(IPFS)  │  │ OpenClaw 执行层 │
│  - 资产存证      │  │  - 元数据索引   │  │  - Agent 运行   │
│  - 权限管理      │  │  - 语义向量    │  │  - Skill 调用   │
│  - 自动分润      │  │  - 能力发现    │  │  - 结果返回     │
│  - 事件日志      │  │  - 推荐引擎    │  │  - 沙箱隔离     │
└──────────────────┘  └──────────────────┘  └──────────────────┘
```

## 技术栈

- **框架：React 18 + TypeScript + Vite
- **UI：** Tailwind CSS
- **Web3：** ethers.js v6 + wagmi v2
- **状态管理：** Zustand
- **图表：** Recharts

## 开发

```bash
cd echonexus
pnpm install
pnpm dev
```

## 经济模型

### 使用权收益分配（优化版）

- 创作者/所有者: **75%**
- OpenClaw 执行节点: **8%**
- 协议层: **12%**
- 生态基金: **5%**

### 衍生权收益分配

- 一次性衍生费：亲代 70% / 生态 20% / 协议 10%
- 使用版税：衍生品所有者 60% / 亲代累计 30% / 协议 10%

### 扩展权收益分配

- 资产所有者: 75%
- 场景受益人: 15%
- 协议: 10%
