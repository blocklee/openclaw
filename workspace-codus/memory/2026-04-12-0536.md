听风: openclaw 的 dreaming 系统啊
assistant: OpenClaw 的 **Dreaming（梦境）系统** 是一个实验性的**背景记忆整合系统**，属于 `memory-core` 插件的核心功能。它的设计理念是帮助 OpenClaw 自动将短期记忆信号转化为长期记忆，同时保持整个过程的可解释性和可审查性。

## 🎯 核心功能

### 1. **三个睡眠阶段的整合模型**
Dreaming 系统模拟了人类睡眠的三个阶段：

| 阶段 | 功能 | 持久化写入 |
|------|------|------------|
| **Light（浅睡）** | 摄入并整理近期记忆信号 | ❌ 不写入 MEMORY.md |
| **Deep（深睡）** | 评分并晋升长期记忆候选 | ✅ 写入 MEMORY.md |
| **REM（快速眼动）** | 提取主题和反复出现的想法 | ❌ 不写入 MEMORY.md |

### 2. **输出内容**
- **机器状态**：`memory/.dreams/` 目录下的 recall 存储、阶段信号、摄入检查点和锁
- **人类可读输出**：
  - `DREAMS.md`（或 `dreams.md`）：包含睡眠阶段的总结和梦境日记
  - `memory/dreaming/<phase>/YYYY-MM-DD.md`：每个阶段的详细报告文件
  - 长期记忆晋升仍然只写入 `MEMORY.md`

### 3. **梦境日记（Dream Diary）**
系统会在每个睡眠阶段后，通过背景子代理自动生成**梦境日记**，记录记忆整合的过程。这些日记主要用于人类阅读和审查。

## 🚀 启用方式

在 `openclaw.json` 中配置：

```json
{
  "plugins": {
    "entries": {
      "memory-core": {
        "config": {
          "dreaming": {
            "enabled": true,
            "timezone": "Asia/Shanghai",
            "frequency": "0 3 * * *" // 每日凌晨3点运行
          }
        }
      }
    }
  }
}
```

## 🛠️ 管理方式

### 1. Slash 命令
```bash
/dreaming status    # 查看状态
/dreaming on        # 开启
/dreaming off       # 关闭
/dreaming help      # 帮助
```

### 2. CLI 工具
```bash
# 手动触发记忆晋升
openclaw memory promote
openclaw memory promote --apply

# 解释为什么某个内容会/不会被晋升
openclaw memory promote-explain "关键词"

# 预览梦境阶段的输出
openclaw memory rem-harness
```

### 3. Web UI
通过 OpenClaw Gateway 的 **Dreams 标签页** 可以：
- 查看当前状态和阶段信息
- 监控记忆整合的统计数据
- 查看梦境日记
- 管理历史记忆回放

## 🎯 深层排序信号

深睡阶段使用以下 6 种加权信号进行记忆晋升决策：

| 信号 | 权重 | 描述 |
|------|------|------|
| 频率 | 0.24 | 记忆条目在短期信号中的出现次数 |
| 相关性 | 0.30 | 平均检索质量 |
| 查询多样性 | 0.15 | 不同查询/日期上下文中出现的次数 |
| 新鲜度 | 0.15 | 时间衰减的新鲜度分数 |
| 整合强度 | 0.10 | 多日重复出现的强度 |
| 概念丰富度 | 0.06 | 片段/路径中的概念标签密度 |

## 🔍 特点

1. **可审查性**：所有记忆整合过程都有详细记录，可以追溯
2. **自动化**：通过 cron 作业自动管理整合过程
3. **可定制性**：支持自定义运行频率和时区
4. **安全性**：默认禁用，需要明确开启

需要注意的是，Dreaming 系统目前仍处于 **实验阶段**，但已经提供了强大的记忆管理功能，可以显著改善 OpenClaw 的长期记忆留存效果。
