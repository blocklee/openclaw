## 🎯 Skill 底层原理

### 1. Skill 是什么？

Skill 是一个**文件夹**，包含：
- `SKILL.md` - 技能定义文件（YAML frontmatter + 说明）
- 可选的脚本/工具

```markdown
---
name: weather
description: "Get weather forecasts"
metadata: { "openclaw": { "requires": { "bins": ["curl"] } } }
---
```

### 2. Skill 加载位置（优先级从高到低）

| 位置 | 说明 |
|------|------|
| `<workspace>/skills` | 当前工作区 |
| `<workspace>/.agents/skills` | 项目级 agent 技能 |
| `~/.agents/skills` | 个人技能（跨工作区） |
| `~/.openclaw/skills` | 共享技能（所有 agent 可见） |
| bundled skills | 内置技能 |
| `skills.load.extraDirs` | 额外配置目录 |

### 3. Skill 触发机制

**自动匹配**：当用户消息匹配 skill 的 `description` 时自动激活
```markdown
# weather skill
## When to Use
✅ "What's the weather?"
✅ "Temperature in [city]"
```

**Slash 命令**：`/weather` 直接调用

### 4. 过滤机制（Gating）

Skill 加载时会根据 `metadata.openclaw.requires` 检查：

```yaml
metadata:
  openclaw:
    requires:
      bins: ["curl"]           # 必须存在的命令
      env: ["API_KEY"]         # 必须存在的环境变量
      config: ["browser.enabled"]  # 配置项必须为 true
    os: ["linux", "darwin"]    # 操作系统限制
```

### 5. 运行时注入

```
Agent 启动 → 读取 skill metadata 
         → 注入 env/API key 到 process.env
         → 构建系统提示词（包含 eligible skills）
         → Agent 执行
         → 恢复原始环境
```

### 6. Session 快照

- Session 启动时生成 eligible skills 列表
- 整个会话复用该列表
- 修改 skill 配置需新建会话才生效

---

## 📊 Token 消耗

当有 skills 可用时，会注入到系统提示词：
- **基础开销**：195 字符
- **每 skill**：97 字符 + name/description/location 长度
