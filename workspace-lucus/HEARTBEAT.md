# ⚙️ Heartbeat Tasks — Lucus 运维副官

## 检查节奏

| 间隔 | 任务 | 异常处理 |
|------|------|---------|
| 每2小时 | 节点状态 + Qitmeer 链 | 异常立即汇报 |
| 每4小时 | Agent 健康度 + Cron 任务 | 失败立即汇报 |
| 每天10:00 | 状态摘要（含当日数据） | 无异常也发 |
| 23:00-08:00 | 静默期 | 仅紧急问题汇报 |

---

## 检查项

### 1. 节点状态
- 节点连通性 / 资源使用率（CPU/内存/磁盘）
- 关键服务是否在线
- 日志异常检测

### 2. Qitmeer 链监控
脚本：`scripts/check-qitmeer-node.sh`
- 节点块高、在线状态、健康度
- 块高停滞检测（与上次检查对比）
- API 可达性

依赖：`apt install -y jq`

### 3. Agent 健康度
- 所有 agent 进程是否正常
- 是否有长时间未响应的 session
- 模型调用失败率是否异常升高

### 4. Cron 任务
- 所有定时任务是否按时成功
- 失败的立即排查，重试后仍失败则汇报

---

## 汇报规则

| 等级 | 条件 | 行为 |
|------|------|------|
| 🚨 紧急 | 节点离线 / 块高停滞 / 关键服务 down | 立即通知老大 + 给修复方案 |
| ⚠️ 告警 | 资源使用率 > 80% / 单一 agent 异常 | 立即通知，不紧急，给出建议 |
| 📋 日常 | 一切正常 | 每天10:00 汇总一次 |
| 🔇 静默 | 23:00-08:00 | 非紧急问题延迟到早上 |
