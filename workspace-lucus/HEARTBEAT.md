# Heartbeat Tasks

## 节点状态检查

每2小时检测一次节点状态：
- 有异常 → 立即汇报
- 无异常 → 静默

每天上午10点发送一次状态摘要（无论是否有异常）。

### 检查项
1. 节点连通性
2. 节点资源使用率（CPU/内存/磁盘）
3. 关键服务状态
4. 日志异常检测
5. Qitmeer节点运行状态（块高、在线状态、健康度）

### 汇报规则
- **紧急异常**：立即发送通知
- **日常状态**：每天10:00发送一次汇总报告
- **静默期**：23:00 - 08:00 期间非紧急问题延迟到早上汇报

## Qitmeer节点监控
检查脚本路径：`scripts/check-qitmeer-node.sh`
- 每2小时自动执行一次检查
- 异常情况（API不可达、节点离线、健康状态异常）立即汇报
- 每日10点状态汇总包含当前Qitmeer节点块高信息

依赖：需要系统安装jq（JSON解析工具），安装命令：`apt install -y jq`
